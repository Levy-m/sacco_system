SACCO FINANCIAL MANAGEMENT SYSTEM
=================================

Files
-----
sacco.py         The main program (menu, members, savings, loans, reports)
storage.py       Saves and loads the data from the JSON file
sacco_data.json  The data file. It is created automatically on first save.

How to run
----------
1. Open the folder in VS Code.
2. Open a terminal (Terminal > New Terminal).
3. Type:  python sacco.py
   (on Linux or Mac use:  python3 sacco.py)

No extra libraries need to be installed. The program uses only the
Python standard library (json, os and datetime).
